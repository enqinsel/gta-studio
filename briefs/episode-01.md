# EP01 — GTA 6's World Explained: Every Confirmed Location

**Status:** First pilot episode; build as soon as the GTA Studio engine is usable.

**Working public title (EN):** `GTA 6's World Explained: Every Confirmed Location`.
**Turkish narration angle:** GTA VI'nın şimdiye kadar Rockstar tarafından doğrulanan dünyası: hangi bölgeler kesin, hangileri fragmanda görülüyor, hangileri yalnızca fan tahmini?
**Language at pilot:** `tr` voice, external `tr.srt`. English-facing public title may be prepared for later. No EN/ES/DE dub spend now.
**Video:** 16:9, landscape, 1920×1080, 30fps; natural length **not a predefined minute count**. Real, verifiable media first.

## Research instructions
- Recheck current Rockstar GTA VI official site/Newswire, trailers, screenshots, media and named People & Places at production time. Record actual publication dates; latest source may have launch-era updates not available in old guides.
- For any location (e.g., Vice City / Leonida areas), only say `confirmed` if verified from official Rockstar source. On-screen trailer observation is not automatically an officially named map location. Keep `CONFIRMED / OBSERVED / FAN THEORY` explicitly separate.
- Do not invent a complete official map, precise travel distances, gameplay mechanics, neighborhood names or boundaries not shown in the source. Use source-accurate cutouts and simple approximate diagrams only with honest labels.
- Interesting narrative structure: where we start / city / outside urban environment / varied places Rockstar actually named / why the scope changes the open-world experience / what remains unknown.

## Pilot editing decisions
- First assemble a **claim-to-media plan** that explicitly identifies each directly relevant genuine clip/still. Narration length follows supported claims and usable media, not the expectation of a 10-minute video.
- Do not mistake comprehensive for exhaustive: the title promises confirmed locations; if evidence does not support a claimed region, leave it out and narrow title language if needed.
- A simple sourced map can explain relationships but cannot be misrepresented as a fully official map or precise geographic reconstruction.
- Optional single reference-video grammar study, only if useful and fast; never install 13 repos or remodel the whole engine to get a pilot.

## Visuals
- Prefer genuine Rockstar clips/screenshots for every claimed area, along with authentic source-context timestamps; build a documentary with context-aware zooms, genuine location reveals, careful map references and almost no text.
- Cyber-noir channel look; **no fake GTA 6 gameplay, generated roads, AI NPCs, unofficial "leaked" footage, or game-style filler**.
- Cover: a real Vice City or Leonida official shot with a premium clean editorial treatment; optional 0–2 words `THE WORLD` / `THE MAP`, no invented visual landmarks.

## End condition
Actually render TR pilot + final SRT + thumbnail; check source coverage and 16:9 quality, provide one short delivery report with rights items for the user's later review. If a claim or visual is not supportable, exclude it rather than padding the runtime.
