# Timecoded edit references

## Goal
For a new motion direction or cinematic outro, inspect two or three relevant gaming documentary, GTA or motion-design sources before authoring. Learn from their cut, proof, sound and closure timing. Use original editorial composition for the VALEA edit.

## Selection
Choose a real published reference because its **editing** is relevant (proof sequences, clean comparisons, map evidence, visual restraint). Record its link, creator, date, exact observed behavior and why it matters. Source video availability and local analysis rights must be respected. If no legally usable local file exists, watch/read available excerpts and make a manual note; don't bypass access restrictions.

## Tool order
1. First, assess whether HyperFrames' existing `reverse-any-video` or `style-sampling` skill, installed for a matching project CLI version, is sufficient. Do not run blind latest-version upgrades.
2. If deeper machine-readable per-shot analysis would materially improve the pilot and an appropriate locally accessible reference video exists, optionally use `JuneYaooo/rea-video`: produce its `VIDEO.md` / report in the project research folder. Python/FFmpeg work must honor the same shared heavy-job lock.
3. If no tool is needed, make a two-minute handwritten/manual production note. **Never block EP01 on competitor-video processing.**

## Record: `research/edit-reference.md`
- Record the reference and date, exact observed time ranges, sampling interval and the evidence source. Distinguish a frame sample, an observed clip, a production breakdown and a measurement of the combined audio.
- How the first 20–40 seconds prove the hook, not just make noise.
- Why and when moving footage is full-screen vs split comparison vs still/evidence panel.
- Typical shot hold ranges observed, **not** mandatory fixed cut duration.
- The concrete visual operations (crop, evidence zoom, match cut, pan, selective annotation) and what each communicates.
- Text and color discipline; music/SFX relationship to narration.
- 2–3 transferable editorial principles and 2–3 habits to avoid.
- How the VALEA episode will be composed using the sourced GTA material.

## Anti-clone rules
Never feed a competitor video into an automatic 1:1 remake flow for this channel. Don't treat software's AIGC/filmed classification as conclusive. Don't copy their exact shot list, highly distinctive motion identity, soundtrack, thumbnail or clips. Use source-provenanced GTA clips and original narration. When analyzing GTA claims, independently verify them from primary/dated sources.

## Style references — grammar, not copyable assets
From `lemomo-ai/lemo-opuscar`, `Visual Investigation` suggests one factual finding per evidence layout and visible uncertainty; `Sci-fi Hologram HUD` suggests **very occasional** measured line/callout motion; `Neon Tubes` illustrates how real physical lighting works rather than neon strokes everywhere. These styles are not installed or reproduced wholesale. Our GTA brand uses original tokens, font choices, layout geometry and motion behavior.
